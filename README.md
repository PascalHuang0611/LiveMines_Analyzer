# LiveMines 注單分析工具

單一 HTML 檔的分析儀表板。所有計算都在你自己的瀏覽器裡完成，**資料不會上傳到任何地方**。

## 怎麼用

**1. 準備一個資料夾**，把要分析的檔案放進去：

| 檔案 | 用途 | 必要 |
|---|---|---|
| `bill_records_*.csv` | 玩家注單 | 玩家分析需要 |
| `game_results_*.csv` | 大盤賽果 | 大盤分析需要 |
| `nicknames.json` | 帳號↔暱稱對照 | 選用，有才顯示暱稱 |

檔名不用改，工具會自己辨識格式。兩種 CSV 可以只放一種，對應的分頁就會有資料。

**2. 開啟工具** → 點「匯入 CSV 資料夾」→ 選你剛剛那個資料夾（是選**資料夾**，不是選檔案）。

瀏覽器會問「要上傳這個資料夾的檔案嗎」，按確定。這是本機讀取，沒有真的上傳。

**3. 用上面的頁籤切換**「玩家分析」與「大盤分析」。

## 兩個分頁在看什麼

**玩家分析**（吃 `bill_records`）
- 依平均單局下注額分成高價值／中階／休閒三群，門檻可以自己調，會記住你上次的設定
- 每群的 RTP、GGR、Hit Rate、九宮格押注偏好
- 全站玩家排行，可用**暱稱或帳號**搜尋（打片段就行，改過名的用舊名字也找得到）
- 點任一位玩家看detail：EXBET 使用狀況、押幾格、押哪幾格、資金歷程圖表

**大盤分析**（吃 `game_results`）
- 營收表現，以及「這個毛利有多脆弱」——拿掉最賠的一局後會變多少
- 功能成本：BG 吃掉多少毛利、Jackpot 獎池累積了多少
- 成長槓桿：在場的人有多少真的下注、有沒有局跑太久卡住節奏

數字旁邊有虛線底線或問號的，**滑鼠移上去會顯示分子分母**。

## 常見狀況

**「已略過 N 筆重複注單」的黃色提示**
匯出檔裡有同一張注單出現兩次，工具只採計一次。統計是對的，但如果要完整資料建議重新匯出。

**「兩個 CSV 的時間範圍不一致」的藍色提示**
兩份檔案不是同一時間撈的。藍色代表逐局比對後沒有缺漏，可以忽略；變成橘色才代表真的有局對不上。

**看不到暱稱**
`nicknames.json` 沒放進資料夾，或放的是舊版。工具會在排行榜上方顯示對到幾個暱稱。

**切換分頁後圖表不見了**
應該不會發生，如果遇到請重新整理並回報。

## 給維護者

`nicknames.json` 含真實玩家帳號與暱稱，**已列入 `.gitignore`，不要提交到這個 repo**（repo 是公開的）。工具改成從使用者選取的資料夾直接讀取，不需要隨程式一起發布。

本 repo 不含任何玩家資料、注單或匯出檔。
